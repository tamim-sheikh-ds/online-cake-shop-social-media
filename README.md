# Online Cake Shop — Social Media Setup & Organic Marketing

Project Overview

This project involved organizing and optimizing the existing Facebook Page and Instagram profile for Online Cake Shop, a custom cake business based in Kathmandu, Nepal.

The goal was to improve the business's social media presence, organize product presentation, maintain consistent branding, and support organic marketing to connect with potential customers.
